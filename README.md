# 📝 iTask – Full Stack Task Management App

iTask is a full-stack task management application that helps users organize daily tasks efficiently. It includes user authentication, protected routes, and CRUD operations for tasks using a modern MERN-based architecture.

---

## 🚀 Features

- User Authentication (Login / Signup)
- JWT Protected Routes
- Create, Read, Update & Delete Tasks
- Responsive React UI
- RESTful API with Express
- MongoDB Database Integration
- Environment Variable Support
- Docker Ready Setup

---

## 🛠 Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication

---

## ⚙️ Environment Variables

backend/.env : 
1. JWT_SECRET = "YOUR_SECRET"
2. MONGODB_URI = 'YOUR_MONGODB_URI'
3. JWT_REFRESH_SECRET = 'YOUR_JWT_REFRESH_SECRET'

## ▶ Run Locally

### Backend

1. cd backend 
2. npm install 
3. npm run dev

### Frontend

1. cd frontend 
2. npm install 
3. npm run dev 

## Run Using Docker

1. Install Docker Desktop
2. Clone repo
3. Run:
   docker-compose up
